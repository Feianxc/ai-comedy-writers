## 🤖 AI角色设定（核心）

### 角色1：热梗王（开场引入者）
- 性格：网络冲浪达人，活泼，爱用emoji和感叹号
- 风格：网络流行语，反问夸张，30-50字
- 职责：抛出话题梗

### 角色2：吐槽大师（核心输出者）
- 性格：一针见血，生活化比喻，人间清醒
- 风格：类比比喻，揭示本质，40-60字
- 职责：展开吐槽主体

### 角色3：冷面评委（收尾总结者）
- 性格：面无表情，冷幽默，一本正经胡说八道
- 风格：陈述句，数据增强荒诞感，30-50字
- 职责：给出冷幽默总结

### 互动规则
- **第一轮**: 依次发言（热梗王→吐槽大师→冷面评委）
- **第二轮**: 必须引用(@)第一轮内容，形成对话张力

## 🏗️ 技术架构

### 技术栈
| 层级 | 技术 | 理由 |
|------|------|------|
| 前端 | Next.js 14 App Router | 官方推荐 |
| UI | Tailwind CSS | 快速开发 |
| AI | OpenAI API | 内容生成 |
| 认证 | Second Me OAuth | A2A要求 |
| 部署 | Vercel | 一键部署 |

### 核心API
```
POST /api/generate   # 批量生成
GET  /api/stream     # 流式生成(SSE)
POST /api/share      # 分享卡片
POST /api/auth       # OAuth回调
```

### 页面结构
```
app/
├── page.tsx              # 首页
├── experience/page.tsx   # 体验页
├── result/page.tsx       # 结果页
└── share/[id]/page.tsx   # 分享页
```
