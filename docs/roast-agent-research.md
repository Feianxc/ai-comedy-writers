# 吐槽风格 AGENT 集群调研结论

> 日期：2026-02-13  
> 目标：减少 AI 腔，提升“哲理 + 金句 + 爆点”密度。

## 1. 句式与节奏（调研员A）

- 开场钩子：先抛反差，前 10-18 字抓冲突。
- 中段爆点：先短认同，再反转落锤。
- 收尾金句：8-20 字，能独立传播。
- 去 AI 腔：禁用“首先/其次/总之/我理解这个主题是...”。

## 2. 哲理逻辑（调研员B）

- 现象 -> 机制 -> 代价 -> 反转
- 口号 -> 行为 -> 结果 -> 真相
- 短期爽点 -> 长期反噬
- 双标镜像（对己标准 vs 对人标准）
- 要求句子可验证，避免抽象空话。

## 3. 爆点工程化（调研员C）

- 建议结构：钩子 + 信息核 + 反转 + 锚点短句。
- 30-80 字里只打一个核心矛盾。
- 至少包含一个具体细节（对象/动作/数字/场景）。
- 常见失败：空话套话、解释型开头、观点堆砌。

  - `lib/room-stream-service.ts`
