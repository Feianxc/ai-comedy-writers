## 1. 页面清单

| 路径 | 页面名称 | 用途 | 核心组件 |
|------|----------|------|----------|
| `/` | 首页 | 产品介绍 + 登录入口 + 话题选择 | `HeroSection`, `TopicList`, `LoginButton` |
| `/experience` | 体验页 | AI吐槽生成流式展示 | `StreamContainer`, `MessageBubble`, `PersonaSelector` |
| `/result` | 结果页 | 吐槽内容展示 + 分享 + 投票 | `ResultCard`, `ShareButton`, `VoteButton` |
| `/share/[id]` | 分享页 | 公开卡片展示 | `PublicCard`, `CTAButton` |

### 页面组件树结构

```
app/
├── page.tsx                          # 首页
│   ├── HeroSection                   # 产品介绍区

├── experience/
```

## 3. 页面详细流程

### 3.1 首页 (`/`)

#### 入口条件
- 直接访问域名
- 从其他页面返回
- 从分享页CTA跳转

#### 页面状态
| 状态 | 描述 | UI表现 |
|------|------|--------|
| `loading` | 初始化中 | 加载动画 |
| `authenticated` | 已登录 | 显示用户信息 + AI人设选择器 |
| `unauthenticated` | 未登录 | 显示登录按钮 |

#### 用户交互流程

```
┌─────────────────────────────────────────────────────────┐
│                      首页加载                            │
└────────────────────────┬────────────────────────────────┘
                         │
                         ▼
              ┌──────────────────────┐
              │  检查登录状态        │
              │  (检查session/cookie)│
              └──────────┬───────────┘
                         │
              ┌──────────┴───────────┐
              │                      │
             已登录                 未登录
              │                      │
              ▼                      ▼
    ┌──────────────────┐   ┌──────────────────┐
    │ 显示欢迎信息     │   │ 显示"开始吐槽"   │
    │ 显示AI人设选择器 │   │ 按钮 → 跳转OAuth │
    └─────────┬────────┘   └─────────┬────────┘
              │                      │
              ▼                      │
    ┌──────────────────┐             │
    │ 用户选择人设     │             │
    │ (毒舌/阴阳/...)  │             │
    └─────────┬────────┘             │
              │                      │
              ▼                      │
    ┌──────────────────┐             │
    │ 浏览热门话题     │             │
    │ 或输入自定义话题 │             │
    └─────────┬────────┘             │
              │                      │
              ▼                      │
    ┌──────────────────┐             │
    │ 点击"开始吐槽"   │◄────────────┘
    │ → 跳转/experience│
    └──────────────────┘
```

#### 决策点
1. **登录检查**: 未登录用户必须先完成OAuth
2. **人设选择**: 可选择跳过，使用默认人设
3. **话题选择**: 可选择热门话题或自定义输入

#### 成功路径
用户已登录 + 选择人设 + 确定话题 → 进入体验页

#### 错误处理
| 错误场景 | 处理方式 |
|----------|----------|
| OAuth失败 | 显示错误提示，提供重试按钮 |
| 网络超时 | 显示离线提示，缓存用户选择 |
| Session失效 | 自动跳转登录，保持话题选择 |

#### 决策点
1. **SSE连接**: 首选SSE流式输出，失败则降级为轮询
2. **投票机制**: 每用户限投1票，可修改
3. **提前结束**: 用户可选择提前结束

#### 成功路径
用户点击吐槽 → SSE流式输出两轮对话 → 用户投票 → 跳转结果页

#### 错误处理
| 错误场景 | 处理方式 |
|----------|----------|
| SSE连接失败 | 降级为批量API + 轮询 |
| AI生成超时 | 显示"AI正在思考..."，30秒后提示重试 |
| 生成内容异常 | 使用预设段子库保底 |
| 网络中断 | 自动重连，恢复对话历史 |

## 4. 跨页面交互

### 4.1 数据传递

| 源页面 | 目标页面 | 传递方式 | 数据内容 |
|--------|----------|----------|----------|
| `/` | `/experience` | URL Query | `topic`, `personaId` |
| `/experience` | `/result` | URL Query | `roastId` |
| `/result` | `/share/[id]` | 路由参数 | `shareId` |
| `/share/[id]` | `/` | URL Query | `ref=share`, `topic` |

### 4.2 状态共享

#### Session Storage (页面间临时数据)
```typescript
interface SessionData {
  userPersona?: string;      // 选择的AI人设
  lastTopic?: string;         // 上次的话题
  roastHistory?: string[];    // 最近的roastId
}
```

#### Local Storage (持久化数据)
```typescript
interface LocalData {
  userPreferences?: {
    defaultPersona?: string;  // 默认人设
    favoriteTopics?: string[]; // 收藏的话题
  };
  sessionToken?: string;       // OAuth Token
}
```

### 4.3 服务端状态管理

#### Cookie/Session

```typescript
interface ServerSession {
```

### 5.3 API失败处理

| 失败类型 | HTTP状态 | 重试策略 | 降级方案 |

| 服务错误 | 500 | 1次重试 | 显示错误提示 |
| 限流 | 429 | 等待后重试 | 显示"稍后再试" |
| 业务错误 | 400 | 不重试 | 显示具体错误 |

```
用户点击登录
      │
      ▼
GET /api/auth/login
      │
      ▼
302 → https://api.second.me/oauth/authorize
    ?client_id=xxx
    &redirect_uri=https://app.com/api/auth/callback
    &response_type=code
    &scope=user:read
      │
      ▼
【用户在Second Me页面授权】
      │
      ▼
302 → https://app.com/api/auth/callback?code=xxx
      │
      ▼
服务端处理:
1. 用code换取access_token
   POST https://api.second.me/oauth/token
2. 获取用户信息
   GET https://api.second.me/v1/user
3. 存储session
4. 重定向到首页
      │
      ▼
用户已登录状态
```
